Shipment implementa el dominio de envíos, cliente REST de courier, JWT y pertenencia, configuración central, Docker y pruebas. [Estado de implementación e integración por issue](ESTADO-ENTREGA.md).

Las propuestas de los demás servicios y las imágenes publicadas se verifican por separado: la suite aislada de shipment no certifica la entrega distribuida.
